# XCcv 多功能视觉平台 · 使用文档

版本 V0.8.3 ｜ 五步落地：**标注 → 训练 → 测试 → 部署**（另有流程图编排与模型工具）
文档维护：Arbhh

主界面左侧导航切换平台；右上角显示推理服务状态；每个平台是独立进程，互不影响。

## 1. 标注平台

- 打开：主界面「标注平台」卡片，或把数据集文件夹拖到桌面快捷方式。
- 智能多边形（S 键 / 「创建智能多边形」）：左键点目标=并入，Shift+左键=挖除，
  右键撤销上一锚点，双击或 Ctrl+左键完成。首次使用会后台加载 SAM 模型，
  顶部橙色横幅显示进度，就绪后自动消失。
- 画笔（B 键）：左键拖动涂画，滚轮或 [ ] 调粗细；右键拖动=擦除。
- 普通多边形（N）/ 矩形（R）/ 保存 Ctrl+S。标注结果存 labelme json。
- 批量预标注：「工具 → AI 批量预标注」对整个文件夹先跑模型再人工修正。

## 2. 训练平台

- 新建项目：选数据集目录（labelme 结构）→ 选模型（yolo11n / resnet18 /
  maskrcnn18/50；无监督异常检测 cif / patchcore / subspacead）→ 训练参数
  （快速模式开箱即用，专家模式可全量调参）。
- 免训练范式（异常检测）在快速模式下自动换用「支持集张数/增强样本数」
  档位（快速建库/均衡建库/高质量建库），不出现轮次语义。
- 「负样本训练」默认开启（OK 负样本抑制误检）；「P2 小目标检测头」按需勾选；
  「数据体检」与「智能推荐配置」辅助参数决策。
- 训练完成后在「历史记录」查看曲线与指标，「对比所选」可比较两次训练。

## 3. 测试平台

- 加载模型：项目最新模型（best.pt）或直接选权重文件（.pt/.engine）。
- 单图预测 / 批量测试（可设输出目录、置信度）；4K 大图勾「分块推理」。
- 项目复盘：批量一次 → 阈值面板拖线即时重新分组（不重推理）；双击缩略图
  在平台内查看检测结果叠加图（绿框=过阈检出、红框=被过滤检出；异常检测/
  分类显示图像分数或预测类别横幅）；「应用到检出流程」「生成流程图模板」
  完成后弹窗可一键「前往流程图界面」加载。
- 界面语言：主界面「设置」切换中文/English，各窗口自动重建生效。

## 4. 模型工具

- **模型加速**：权重 → TensorRT 引擎（.engine）。输入尺寸支持 `640` 或
  `高x宽`（如 `586x1920`，与训练尺寸一致时矩形模型效果最佳）；导出需
  NVIDIA GPU + TensorRT。加速引擎在测试平台直接加载。
- **剪枝**：resnet18 等分类模型训练前剪枝（YOLO 家族需专家模式环境变量）。
- **缺陷生成**：Web 画布合成缺陷样本，资产跨会话保留。
- **流程图**：57 个内置算子（预处理/定位/测量/逻辑/AI 桥接/检出过滤/输出）
  在画布混合编排；可从 5 个官方模板新建；整目录批量输出统一 JSON + 蒙版图；
  流程连同模型打包为明文 .xvap 流程包，供测试平台与推理服务直接加载。

## 5. 部署平台（推理服务 / 模型加载 / C# 测试）

- **推理服务**：点「启动服务」，默认 `127.0.0.1:8600`，API Key 自动生成；
  日志写入 `platform_data\logs\service.log`（启动失败原因也会落盘）。
  服务自带上传护栏（单请求体/像素总量/批量张数上限，超限返回 400/413 提示），
  管理操作（如远程停服）需携带 API Key。
- **模型加载**：向运行中的服务加载 .pt/.engine（明文产物直读，模型常驻内存）。
  窗口顶部实时显示服务真实状态；服务未启动时加载按钮禁用。
- **C# 测试**：一键编译 Demo 上位机并连接服务（SDK 为单文件，
  .NET Framework 4.5+，系统 csc 直接编译）。

## 6. 目录说明（源码运行布局）

```
<源码根>\
  xccv\ labelme\    ← 平台源码（Python 包）
  run_main.bat      ← 主界面启动脚本（根目录唯一启动入口）
  install.bat       ← 一键环境安装器入口
  scripts\          ← 子平台启动 bat（回溯根定位）+ run_tools.py
  docs\             ← 使用文档 / 操作流程手册 / 接口契约（result_schema.md）与项目简介
  xccv\engine\weights\ ← 引擎权重目录（不随仓库分发，各族子目录见下）
  platform_data\    ← 用户数据（日志/项目/训练产物），可整目录备份
```

日志统一在 `platform_data\logs\`（crash.log / main.log / training.log / service.log 等）。
模型权重与示例数据不随仓库分发：基准权重（YOLO / torchvision / SAM / DINO）可用
`python tools/download_weights.py` 一键下载（`--list` 查看清单），其余按 README
「权重与示例数据」表格自行放置；缺陷合成示例图在发布页独立数据包。

## 7. 常见问题

- **加速引擎加载报"需要 GPU/TensorRT"**：.engine 与显卡算力、TensorRT 版本
  绑定，请在导出时的同款机器上使用，或改用 .pt。
- **智能多边形没有反应**：等待顶部横幅消失（模型就绪）后再点；权重缺失
  时状态栏会给出放置路径提示。
- **推理服务无法启动**：查看 `platform_data\logs\service.log` 尾部；端口
  被占用时换端口或结束旧 python 进程。
- **上传返回 400/413**：请求体、单图像素总量或批量张数超过服务上限
  （默认 100 MB / 50M 像素 / 每批 32 张），缩小批量或分辨率后重试。
