# XCcv 操作流程手册（V0.8.2）

> 零基础用户按平台分章：**标注 → 训练 → 测试 → 部署 + 模型工具 + 流程图**。
> 每章按"目标 → 步骤 → 产出"组织；命令与参数只讲常用项，全文以中文界面为准。
> 文档维护：Arbhh

## 一、标注平台（labelme）

1. 打开方式：主界面「标注平台」卡片；顶部「打开目录」选择数据集文件夹
   （结构：图片 + 同名 .json 标注，子文件夹按类组织）。
2. 标一个缺陷：`矩形`（Ctrl+R 画框）或 `多边形`（描轮廓）；画完在弹出的
   标签框输入缺陷名（如「黑点」）。同一目录用统一命名。
3. 小目标/复杂轮廓：按 `S` 启动 **AI 智能多边形**（点一下目标自动描边，
   左键加点并入 / Shift 挖除 / 双击完成）；`B` 画笔模式涂改。
4. 批量预标注：「工具 → AI 批量预标注」，选好模型批量跑，再人工修正。
5. **漏标复核**：「帮助 → AI 复核当前图（疑似漏标）」——选一次检测权重
   （自动记住），模型检出但与现有标注不重叠的区域会列出，勾选接受。
6. **良品图（OK）**：放进名为 `OK`/`良品`/`正常`/`合格` 的子文件夹且
   **不标注**——训练时勾「负样本训练」自动当背景学（列表里带 `[OK]` 徽标）。
   右键图片可「把所在文件夹设为 OK/良品目录」。
7. **忽略区域**：反光、丝纹等界限模糊区域画矩形/多边形、标签填
   `__ignore__`——训练/评估时与区域重叠大（>50%）的标注自动剔除、区域
   内误检不计（近似语义；区域内背景仍参与学习，别把它当"删除标注"用）。
8. 标注质量要点：「帮助 → 标注质量要点」。

## 二、训练平台

1. 「＋新建项目」：项目名 + 数据集路径 + 任务类型（检测/分割/分类/
   无监督异常检测/OCR）+ 模型。新手直接选轻量模型（yolo11n /
   yolo11n-seg / maskrcnn18 / resnet18；异常检测选 patchcore；字符识别选 crnn）。
2. 数据体检：点「数据体检」看提示/警告（类别不均衡、样本过少、疑似重复、
   **OK 负样本比例**、**缩放后过小实例**、**忽略区域**），按建议处理或忽略。
   「数据集可视化」下方的**数据网格**是全部图片的缩略图墙（可按标签/
   只看 OK/只看未标注/含忽略区域筛选，双击用系统看图打开；切换筛选后
   缩略即时回显）。**训练 / 验证划分环状图**与下方「训练集比例」「验证集
   比例」参数实时联动——改参数即重绘，环心直接显示当前比例。
3. 拿不准参数：点「智能推荐配置」一键应用（冻结骨干/工业优化/轮次/增强概率）。
   **免训练范式（异常检测）**没有轮次概念：快速配置自动换用「支持集张数 /
   增强样本数」档位（快速建库 2 张 / 均衡建库 4 张 / 高质量建库 8 张），
   专家模式隐藏轮次类参数、按阶段化进度（特征抽取与建库 → 标定 → 验证评估）
   展示进度；Loss 区显示免训练文案与 AUROC 曲线。
4. 开始训练：右侧「开始训练」。训练中看曲线、逐轮指标；可中途停止
   （YOLO 除外，由引擎控制）。
5. 训练完成：**逐类指标表**（每类 TP/FP/FN/精确率/召回率/AP@50，列宽
   随内容自适应）+ Loss 自动判读（欠拟合/过拟合提示）+ OK 负样本误检统计。
6. **图像增强策略**的「效果预览」对**全部勾选算子**生效：每算子按启用概率
   掷硬币后应用到抽样图，预览信息标注本次实际生效的算子；调任何算子参数
   或点「换一张」即时重预览。各算子的含义见控件悬停提示。
7. 可选项（专家模式）：负样本训练（默认开）、P2 小目标头（YOLO）、
   slim 头（maskrcnn18）、灰度训练（颜色无判别意义时）、切图训练（大图
   小目标）、**确定性训练**（同机同种子可复现，默认关）。
8. 产物：每个训练记录 = best.pt（明文权重）+ metrics.json + **run_manifest.json**
   （训练环境/数据指纹/完整参数，现场复现与追溯用）。

## 三、测试平台

1. 底部「标准 / 项目复盘」两个页签（状态栏左侧）：
   - **标准**页：自由加载权重与图片做单图/批量测试；
   - **项目复盘**页：选项目 + 训练记录（自动定位权重），默认批量运行
     训练数据集（也可「浏览…」换任意生产图文件夹），一次加载只推理一次，
     结果落临时缓存，关平台或重选项目时自动清理。
2. 单图测试（标准页）：打开图片 → 自动推理；调置信度/IOU 滑条实时看效果
   （IOU 默认 0.20）。
3. 批量测试（标准页）： 「批量运行…」选文件夹（含子文件夹）。完成后：
   - 统计摘要（检出数/每类检出/耗时 min·p50·avg·max/显存；
     首张已自动预热；**疑似 GPU 掉频告警**按提示排查）；
   - **复判与回流**：逐图打「正常/漏检/过检/存疑」（有建议列），
     问题图一键「回流到训练集」（带原标注或预测框 → 待标注目录）。
   - **模型 A/B 比对**：加载第二个权重对同一批图复推，逐图判定
     A 优/B 优/一致，统计行下方有**总体优劣比例条**；比对结果按
     模型+参数缓存——误触关闭窗口重开后选同一 B 模型直接复用，
     不重新推理，产物 `检出结果/比对.json`。
4. **项目复盘**（项目复盘页，推荐日常验收用）：
   - 缩略墙上方「**已评估 / 未评估**」切换：已评估显示 正确/漏检/过检
     三组（OK 图判定与训练平台目录名规则一致）；未评估显示无 GT 生产图
     按**有检出过阈=NG / 无检出=OK** 分两组，供肉眼确认；
     双击缩略图在**平台内查看检测结果**：带框任务显示检出叠加——
     绿框=过阈检出、红框=被阈值过滤的检出（取自复盘保存的结果，
     不重新推理）；异常检测/分类显示图像分数或预测类别横幅；
     窗口内保留「用系统看图打开」入口。
   - **维度阈值**面板（V0.7.2 扫描曲线口径）：曲线读数 = 阈值线所在
     位置的**总数**——绿=正常（阈值下命中 GT 的检出数）、红=过检
     （阈值下未命中的检出数，含 OK 误检）、蓝=漏检（GT 总数−正常，
     含被阈值筛掉的命中）；恒有 正常+漏检=GT 实例总数。拖动阈值线时
     三条曲线上的读数就是该阈值下的实际分组数量。坐标轴为固定轴：
     置信度恒 0~1，其余维度从 0 到本批最大值外扩取整；y 轴=数量。
     阈值线**拖动范围被钳回固定轴内**（不会滑出轴外丢失），悬停即
     加粗提示可抓取；阈值可**拖线**或在「阈值」框**直接键入**，调完
     即时重新分组，**不重新推理**；勾「参与过滤」控制该维度是否进
     流程图；多个维度同时启用时，曲线按"其余维度取各自阈值"的联合
     口径现算。
   - 点「应用到检出流程」把置信度写进项目检出流程；点「生成流程图模板」
     把所有启用维度编排成流程图，落模型文件夹 `flow/<时间>_<模型名>.json`；
     操作完成后弹窗提示，点「前往流程图界面」直接拉起流程图平台并
     载入该流程（已在运行时经单实例转发直达）。
   - 批量参数（置信度 conf / IOU）在复盘页控制行可直接改，改后点
     「开始复盘」重新推理。
5. 4K 大图：勾「4K 大图分块推理」（与切图训练配对）。
6. 导出：批量设置里选检出结果格式（xcv / labelme / coco）。
7. **界面语言**：主界面「设置」对话框提供「界面语言」（中文/English）——
   与界面主题同一入口；保存后**各窗口自动切换语言**（主界面即时重建，
   各平台窗口自动重建，无需重启进程），偏好所有平台共享。英文覆盖
   常驻界面文案、悬停提示、对话框、图表文本、算子显示名与流程图画布
   （工具栏/节点库/画布节点标题）；运行日志正文暂为中文，
   详见《项目总体约定》§五。

## 四、部署平台（推理服务）

1. 「推理服务」卡 → 启动服务；首次加载约 5~10 秒。服务运行中页面顶部有
   **GPU 状态条**（性能状态/温度/功耗/利用率；P6/P8 即掉频，见
   `docs/显卡掉频排查指引.md`）。
2. 模型加载：模型路径 + 别名（C# 按 model_id 调用）。接口文档：
   服务运行时访问 `http://127.0.0.1:端口/docs`。
3. **一致性自检**：选同一张图，本地与 HTTP 服务各推理一次并逐框对比
   （IoU≥0.98、分数差<0.02）——「两边不一样」一键定位。
4. C# 上位机：随包 `XCcv.Vision.Sdk.cs` + Demo（部署平台第三卡一键编译）。
5. 关闭窗口=服务继续运行（托盘）；托盘菜单可停止/退出。

## 五、模型工具

1. **加速**：选训练记录 → TensorRT FP16/FP32 导出 .engine（GPU 必须；
   换显卡后需在本机重新加速）。
2. **剪枝**：分类/R-CNN 走真实剪枝；YOLO 默认快速失败（专家模式
   XCCV_YOLO_PRUNE=1 强制）。
3. **迁移学习**：指定起始权重继续训练。
4. **缺陷生成**：用 AI 生成合成缺陷样本扩充小类别（第四卡独立窗口）。
5. 选择模型后底部有**模型档案**行：类别数/OK 负样本/数据指纹/训练环境。

## 六、流程图平台（传统视觉 + AI 级联）

1. 节点库左列，拖入画布连线；「运行预览」单步看输出；运行日志面板排错。
   "检出过滤"类除置信度/宽高/面积/区域外，还有 **短长边过滤、前景占比
   过滤、灰度差过滤**（阈值面板一键生成的流程图即由这些节点编排）。
2. 官方模板 9 个（含 **级联：检测→裁图→二级分类复判**、级联分割、
   全部目标合并等），模板入参替换即可用。
3. 批量运行：统一 JSON + 蒙版图落盘；可打包 .xvap 给部署服务。
4. 外部算子：HALCON（24.11）/VisionMaster（4.4，需硬件授权）节点。

## 七、典型闭环（建议路径）

```
标注 30~50 张 → 训练（轻量模型+负样本）→ 测试平台批量看分布/逐类表
  → 漏标复核+回流问题图 → 再训练 → 满意后 加速导出 → 部署服务
  → 产线新图复验阈值（检查单：测试集阈值 ≠ 产线全局）
```
