# 快速上手

本文档带你从零跑通第一个检测项目：**标注 → 训练 → 测试**。

（English version: [quickstart_EN.md](quickstart_EN.md)）

## 0. 准备数据

把待标注图片放入一个文件夹（支持 jpg / jpeg / png / bmp / webp，含子文件夹）。

## 1. 标注

1. 打开主界面（根目录 `run_main.bat`），点击「标注平台」卡片；
2. 菜单「文件 → 打开目录」选择图片文件夹；
3. 按 `Q` 新建多边形 / 按 `W` 新建矩形；第一次标注会提示创建类别文件（labels.txt）；
4. AI 辅助（可选，需先按 README 放置 SAM 权重到引擎权重目录 `xccv/engine/weights/sam/`，或一键下载）：
   - 按 `S`：智能多边形——左键点目标，实时预览轮廓，右键撤销锚点，回车确认；
   - 按 `B`：画笔模式——左键笔画塑形（并集）、右键挖除（差集）；
   - 按 `L`：对当前图执行智能标注；「工具 → AI 批量预标注」可整目录批量；
5. 标注结果自动保存为图片同名 `.json`（labelme 格式）。

## 2. 训练

1. 回主界面，点击「训练平台」卡片 →「新建项目」：
   - 填项目名，选择数据集目录（第 1 步的图片文件夹）与模型输出目录；
   - 选择任务类型：分类 / 目标检测 / 实例分割 / 无监督异常检测 / OCR 字符识别；
2. 进入项目 → 选模型（检测推荐 `yolo11n`，分割推荐 `yolo11n-seg` 或 `maskrcnn18`，
   分类推荐 `resnet18`，异常检测推荐 `patchcore`（零训练基线）/ `cif`（少样本超图）/
   `subspacead`（少样本 PCA 子空间），OCR `crnn`）；
3. 「快速配置」模式会按数据情况推荐参数；需要细调时切换「专家模式」（增强策略、工业优化、
   训练加速、切图训练等）。项目信息页提供数据网格（按标签 / OK 负样本 / 未标注筛选）、
   随训练/验证比例实时重绘的划分环形图与图像增强实时预览；
4. 点击「开始训练」，在训练可视化页查看损失与 mAP 曲线、逐类指标表与 Loss 判读；
   训练完成后在项目模型目录产出 `best.pt`。

> 样本太少？先用「缺陷样本合成」卡片把缺陷贴图融合到良品图上扩充数据，再回到训练平台。

## 3. 测试

1. 主界面点击「测试平台」卡片；
2. 上方选择项目 →「加载该项目最新模型」（或「选择权重文件…」直接选 `.pt`）；
3. 「打开图片… / 打开文件夹…」选择待测图片，A / D 键切换上下张；
4. 调节置信度 / IOU 滑条（默认 0.25 / 0.20）实时查看效果；「批量运行…」可对整个文件夹推理并导出：
   - `检出结果/`：每图一个 JSON（统一契约 / labelme / COCO 可选）；
   - `可视化/`：渲染图；
   - `摘要.json`：每类检出数与耗时统计（含 GT 匹配统计，供阈值面板使用）。

大幅面图片（如 4K）勾选「4K 大图分块推理」可显著提升小目标检出。

### 项目复盘

底部页签切换到「项目复盘」：选定项目与训练记录后自动对训练数据集批量推理一次，之后调阈值零重复推理。

复盘页按 **已评估 / 未评估** 解耦（顶部切换）：

- **已评估**：结果按 正确 / 漏检 / 过检 三组缩略图展示；在维度阈值面板拖线或键入阈值
  （置信度 / 面积 / 短边 / 长边 / 灰度差），扫描曲线给出该阈值处三组各自的**图数**（与分组同口径），
  即时重新分组；
- **未评估**：无标注生产图按 OK / NG 两组展示（NG = 有检出通过阈值的图），曲线与数字行随之切换口径；
- 复判结果可回流到数据集「待标注」；「模型 A/B 比对」逐图对比两个权重（相同参数与权重的比对结果
  会缓存复用，误关窗口重开不重推理），并给出总体优劣比例条。

## 4. 流程图（AI + 传统算子）

主界面左侧导航点「流程图」：
1. 「选择文件夹」指定待处理图片目录（图片树可预览）；
2. 「模型目录」选择存放流程 JSON 的目录，「新建」创建空白流程，或选择已有流程 / 模板
   （内置 9 个模板：AI 过滤、级联裁图合并、模板匹配预筛、圆形定位等）；
3. 「编辑流程」打开画布：从左侧节点库拖入 **AI 算子**（目标检测 / 实例分割 / 分类 / 逐图推理）
   与 **传统算子**（裁图、网格分块、结果合并、检出过滤、斑点分析 / 模板匹配 / 找线找圆 /
   测量定位、逻辑判定、外部算子插件后端、输出）连线；
   模型节点需在属性面板选择 `.pt` 权重；
4. 「运行流程」对单图执行并在右侧看结果；「批量运行」对整个目录执行并导出结果；
5. 「打包流程」把流程与模型封入单个 `.xvap`，便于拷贝到其他机器复用。

## 5. 部署平台与推理服务

主界面左侧导航点「部署平台」，三张卡片：

1. **推理服务**：点「启动服务」拉起 HTTP 推理服务（默认 `127.0.0.1:8600`；
   首次启动自动生成 API Key，在面板中可复制 / 重置）。接口一览：
   - `POST /v1/models/load`：把 `.pt` / `.engine` 模型加载为常驻 API；
   - `POST /v1/infer/image`、`POST /v1/infer/batch`、`POST /v1/render/overlay`：
     单帧 / 批量推理与叠加图渲染；
   - `POST /v1/flows/load` + `POST /v1/flows/run`：流程包常驻化运行；
   - `WS /v1/ws/infer`：WebSocket 二进制帧流推理；
   - `GET /docs`：自托管离线 Swagger 文档（无需外网）；
2. **模型加载**：不写代码，用窗口把模型 / 流程包加载为常驻 API（2s 自动刷新状态表）；
3. **C# 测试**：一键编译运行 WinForms Demo（`xccv\service\csharp\build_demo.bat` 同款），
   加载模型 → 推理 → 查看统一 JSON 与叠加图；部署平台还提供「一致性自检」
   （同一张图分别走本地推理与 HTTP 服务，逐框比对）。

无界面部署可直接 `scripts\run_service.bat`（或 `python -m xccv.service.main --port 8600`）。

## 6. 模型工具

主界面「模型工具」卡片（或 `scripts\run_modeltools.bat`）：

1. **模型剪枝**：
   - 训练前剪枝：按项目数据集生成剪枝模型（存入项目「模型储存路径\pruned」，
     训练平台模型下拉自动出现，选择后即迁移学习）；
   - 训练后剪枝：处理某次训练记录的 `best.pt`，输出同目录 `best_pruned.pt`，
     可在测试平台与原模型直接对比；
2. **模型加速（TensorRT）**：把 `best.pt` 导出为 TensorRT 引擎（`.engine`，
   FP16/FP32 可选，需 GPU + TensorRT；YOLO 走 ultralytics 原生路径，
   分类走内存 ONNX→TRT，Mask R-CNN 特征段加速）。导出后测试平台可直接加载 `.engine`；
   引擎与构建时的显卡型号绑定，跨显卡加载会得到明确提示；
3. **百宝箱**（数据工具集工作台，独立窗口 + 顶部搜索）：五个子功能卡片即点即用，
   全部走"扫描预览 → 确认 → 执行"两步式——
   - **一键替换标签**：按标签名批量替换（正则整词可选），同步形状 label 与 flags 键；
   - **删除指定标签**：只删匹配形状 / 整图过滤两模式（删空标注按平台语义移除空
     json；备份目录可选，默认关闭）；
   - **移动标注数据**：按标签/关键字筛选，图片+JSON 成对迁移，支持移动未标注
     纯图片，同名冲突自动跳过并出移动报告；
   - **滑窗裁图**：大图切块导出并同步切分标注（默认参数对齐切图训练
     tile=640 / 重叠 20% / 背景保留 15% / 最小可见率 30%，重叠区目标只归首窗）；
   - **视频切分图片**：间隔帧数 / 目标帧率 / 时长上限三选一抽帧，
     可选感知哈希去重跳过近似帧。

## 常见问题

- **首次训练很慢 / 卡在下载**：训练首次会从官方源下载预训练权重（YOLO / torchvision），
  训练窗口会显示"正在下载预训练权重…"进度条，不再无解释等待；
  离线环境请提前在有网机器下载并放入引擎权重目录 `xccv/engine/weights/`
  （参见 `xccv/engine/offline.py` 注释）；
- **AI 智能标注按钮提示缺权重**：按 README 把 SAM 权重放到 `xccv/engine/weights/sam/`；
- **CIF / SubspaceAD 提示缺骨干权重**：CIF 需 DINO ViT-B/8 权重
  `xccv/engine/weights/dino/dino_vitbase8_pretrain.pth`（或环境变量 `XCCV_DINO_CKPT`）；
  SubspaceAD 优先使用 `xccv/engine/weights/dinov2/`（或 `XCCV_DINOV2_CKPT`）中的本地权重，
  本地缺失时 transformers 可能从 Hugging Face 下载标准 DINOv2 权重
  （可用 `HF_ENDPOINT` 镜像）。权重不随包分发，请按各发布方许可使用；
- **训练报类别不一致**：迁移学习权重必须与当前数据集类别一致；
- **显存不足**：调小批量大小（batch_size），或开启「冻结骨干」「轻量掩码头」等加速选项；
- **切换界面语言**：主界面「设置」→「界面语言」选 English，保存后各窗口自动切换（免重启），
  偏好保存在 `platform_data/ui_lang.json`；个别未覆盖文案会回退中文；
- **模型权重是明文的吗**：是。训练 / 剪枝 / 加速产物均为明文
  （`best.pt`、`best_pruned.pt`、`.engine`）；
- **TensorRT 装哪种**：与本机 CUDA 大版本匹配的 `pip install tensorrt` 即可；
  或设置环境变量 `TENSORRT_DIR` 指向含 `nvinfer_10.dll` 的目录。引擎与生成时
  显卡算力绑定（如 RTX 30 系构建的引擎不能在 20 系加载）；
- **推理服务的 API Key 在哪**：`platform_data/service/config.json`
  （首次启动自动生成；部署平台面板可一键重置）；
- **仓库里为什么没有权重和示例图**：本项目不分发任何模型权重与示例数据——
  权重按各自发布方许可由使用者自取（放置位置见 README「可选：权重与示例数据」表），
  缺陷合成示例图在独立数据包 `XCcv-Platform-testdata-0.8.0.zip` 中；
- **缺陷合成示例图放哪**：把 `XCcv-Platform-testdata-0.8.0.zip` 解压到 `xccv/defectgen/`
  下（得到 `xccv/defectgen/testdata/`）；缺失时合成界面仍可运行，自行指定背景与贴图目录即可。
